# RebRed

Current Windows preview: 1.5-beta. See Docs/PROGRESS-1.5.md for completed work, rule-source review scope and manual verification steps. Source work continues on feat/reliability-layout-1.3 until reviewed.

Selected thumbnails can be reordered inside their grid. On Windows, holding the left mouse button and moving outside the grid starts a native file drag; release over a compatible file-upload target. Escape cancels. Copy selected images remains available if the destination does not accept dragging. No image copies are created by the planner.

Desktop planner for Windows and Linux that prepares Reddit art-commission posts manually.

The actively developed source is in [`App/`](App/); project notes and research are in [`Docs/`](Docs/). The current preview is RebRed 1.2-beta. Download the Windows executable or Linux AppImage from [GitHub Releases](https://github.com/luisonic2000/RebRed/releases/latest).

Read [`Docs/SPEC.md`](Docs/SPEC.md) and [`Docs/STATE.md`](Docs/STATE.md) before changing the application.
