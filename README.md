# RebRed

Windows desktop planner for preparing Reddit art-commission posts manually.

The actively developed source is in [`Projeto/`](Projeto/). Work records, test instructions, decisions, and research are in [`Organizacao/`](Organizacao/). Versioned Windows deliveries are retained locally in `Finais/` and are intentionally excluded from the public source repository.

Read [`Organizacao/SPEC.md`](Organizacao/SPEC.md) and [`Organizacao/STATE.md`](Organizacao/STATE.md) before changing the application.
