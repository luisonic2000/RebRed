# RebRed specification

RebRed is a Windows and Linux desktop planner for preparing Reddit art-commission posts manually.

It may prepare text, apply community-specific draft checks, select existing image files, copy selected file paths to the Windows clipboard on Windows, open a selected subreddit in the default browser, and keep a local posting history. On Linux, users can open the image folder and drag files into a browser upload field.

It must not sign in to Reddit, publish posts, upload media, automate browser posting, create image copies, or store credentials.

The app uses editable community rule packs. Its checks are guidance, not a guarantee that a subreddit will accept a post.
