# RebRed specification

RebRed is a Windows desktop planner for preparing Reddit art-commission posts manually.

It may prepare text, apply community-specific draft checks, select existing image files, copy selected file paths to the Windows clipboard, open a selected subreddit in the default browser, and keep a local posting history.

It must not sign in to Reddit, publish posts, upload media, automate browser posting, create image copies, or store credentials.

The app uses editable community rule packs. Its checks are guidance, not a guarantee that a subreddit will accept a post.
