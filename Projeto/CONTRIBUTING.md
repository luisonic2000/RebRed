# Contributing to RebRed

Thank you for helping review RebRed while it is in beta.

## What to review

- Whether a draft remains local and requires a manual Reddit submission.
- Rule-check accuracy and clear warnings when a community rule is uncertain.
- Link rendering, creator-profile privacy, and the Windows image clipboard.
- Interface clarity, accessibility, and reliability on common Windows setups.

## Local setup

1. Install Python 3.13 or newer.
2. Run `python -m pip install -r requirements.txt`.
3. Run `python app.py`.

Please avoid adding automatic Reddit publishing, sign-in, browser automation, or bulk posting features. RebRed is intentionally a local planner for preparing a manual post.

## Reporting an issue

Include the RebRed version, Windows version, the community profile involved, steps to reproduce the problem, and a screenshot when it helps. Do not include private client messages, payment data, or artwork you do not have permission to share.
